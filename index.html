Telephone

A short program is sent across a room as sound, decoded, run, and sent again. It is never saved, so anything the microphone mishears changes the code.

To try it: turn your sound on and press Start. Each pass takes about 5 seconds. Changed characters are highlighted in black.

Mode

Place the microphone a few metres from the speaker. If they're close together, the code won't change.

Settings

Longer tones are slower but harder to mishear.
