the room is the memory

This program has no storage. Between runs, its source code exists only as sound in the air between a speaker and a microphone. Each pass, it is heard, run, and played back into the room. Whatever the room does to it on the way is kept.

To try it: turn your sound on, leave "simulated room" selected, and press start. Each pass takes about 10 seconds. Letters the room changed turn black. Try moving the distance slider, or edit the code before starting.

room

For the room to have any say, put the mic (a phone, USB or Bluetooth mic) a few metres from the speaker. Right next to each other, the code survives untouched.

signal
